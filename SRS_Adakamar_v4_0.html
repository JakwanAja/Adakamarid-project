Software Requirement SpecificationAdakamar.id

v4.0 4 September 2026
1

Informasi Umum

Adakamar.id adalah platform iklan properti kos khusus area Yogyakarta. Seluruh listing dikelola oleh admin — pemilik kos tidak dapat mendaftar secara mandiri. Tidak ada proses booking atau pembayaran online; calon penyewa menghubungi pemilik kos secara langsung.

Nama aplikasiAdakamar.id
TujuanPlatform iklan properti kos area Jogja — kurated, tanpa booking online
PenggunaPengunjung (Guest) dan Admin
PlatformWeb application
2

Tujuan

  1. Menyediakan platform iklan kos Jogja yang menampilkan listing lengkap dengan informasi harga per tipe sewa (harian, bulanan, tahunan).
  2. Memudahkan calon penyewa menemukan kos yang sesuai kebutuhan melalui pencarian dan filter yang informatif.
  3. Menampilkan informasi lengkap setiap listing: deskripsi kos, harga, fasilitas, lokasi, dan kontak pemilik kos.
  4. Menyediakan panel admin terpusat untuk mengelola seluruh listing kos yang bermitra.
3

Ruang Lingkup

  1. Hanya mencakup kos di area Yogyakarta yang telah bermitra resmi dengan Adakamar.
  2. Unit data utama adalah Kos. Tidak ada entitas Kamar.
  3. Satu kos dapat memiliki harga yang berbeda per tipe sewa: harian, bulanan, dan tahunan. Admin dapat mengaktifkan satu atau lebih tipe sewa per kos.
  4. Tidak ada proses booking atau pembayaran di dalam platform. Calon penyewa menghubungi pemilik kos langsung via kontak yang tercantum di listing.
  5. Lokasi kos dipilih dari daftar kecamatan yang telah ditentukan sebelumnya (dropdown).
4

Fitur Utama

1

Pencarian dan filter kos berdasarkan tipe sewa (harian/bulanan/tahunan), lokasi/kecamatan (dropdown), rentang harga, dan tipe kos (putra/putri/campur).

2

Halaman detail kos: menampilkan deskripsi, informasi umum, harga per tipe sewa, fasilitas, lokasi peta, kontak pemilik, dan ulasan.

3

Label "Plus" di samping nama kos untuk membedakan kos dengan fasilitas unggulan.

4

Ulasan dan rating dari penghuni sebelumnya, terikat ke kos, langsung tampil publik tanpa moderasi.

5

Dashboard admin untuk manajemen seluruh listing kos.

6

Manajemen master fasilitas: admin dapat menambah, mengedit, dan menghapus item fasilitas beserta kelompoknya (fasilitas kamar, bersama, atau sekitar). Saat mendaftarkan kos, admin mencentang fasilitas dari daftar ini.

7

Manajemen akun: register, login, dan login Google (OAuth) khusus untuk guest; manajemen user admin dan guest oleh admin.

8

Pengaturan platform: nama platform dan logo dapat dikelola dari sistem.

5

Teknologi

Laravel 12

Backend, routing, autentikasi manual, dan logika bisnis.

React + Inertia.js

Frontend berbasis komponen, terintegrasi langsung ke Laravel tanpa REST API terpisah.

Tailwind CSS

Seluruh visual utama Adakamar dibuat custom.

shadcn/ui

Hanya untuk komponen utilitas: dialog, dropdown, date picker, tabs, sheet, dan form.

Flowbite

UI untuk panel dashboard admin.

MySQL

Database dirancang dengan pendekatan database-first via MySQL Workbench.

Vite

Build tool untuk aset frontend.

Laravel Socialite

Google OAuth untuk autentikasi guest.

6

Role dan Hak Akses

Admin
  • Mengelola data kos: tambah, edit, nonaktifkan, dan hapus listing beserta foto dan fasilitasnya.
  • Mengatur harga per tipe sewa.
  • Mengisi informasi umum kos (atribut seperti AC, WiFi, kamar mandi dalam) sebagai field tersendiri saat mendaftarkan atau mengedit kos.
  • Mengelola master fasilitas: tambah, edit, dan hapus item fasilitas beserta pengelompokannya.
  • Mencentang fasilitas yang dimiliki kos dari daftar master fasilitas saat mendaftarkan atau mengedit kos.
  • Memberikan atau mencabut label "Plus" pada kos melalui toggle di panel admin.
  • Mengelola kontak pemilik kos (nomor WhatsApp/telepon) yang tampil di setiap listing.
  • Mengaktifkan atau menonaktifkan listing kos.
  • Menghapus ulasan dari dashboard admin.
  • Memantau statistik platform: jumlah kos aktif dan jumlah ulasan.
  • Mengatur nama platform dan logo melalui halaman pengaturan.
  • Mengelola data user: akun admin dan akun guest yang telah terdaftar.
Guest / Penyewa
  • Browsing dan filter kos tanpa login.
  • Melihat detail kos lengkap tanpa login.
  • Mendaftar akun (register) dan login menggunakan email/password atau akun Google (OAuth).
  • Memberikan ulasan dan rating pada kos (wajib login).
  • Menghubungi pemilik kos langsung via nomor WhatsApp/telepon yang tercantum di listing.
7

Kebutuhan Fungsional

Admin

Dashboard
  • Menampilkan ringkasan: jumlah kos aktif, jumlah kos dengan label "Plus", dan jumlah ulasan yang masuk.
  • Menampilkan daftar listing terbaru yang baru ditambahkan.
  • Menampilkan ulasan terbaru yang masuk.
Manajemen Kos
  • Admin menambah dan mengedit data kos: nama, deskripsi, tipe kos (putra/putri/campur), lokasi koordinat Google Maps, foto, informasi umum, fasilitas, dan peraturan kos.
  • Admin mengatur harga per tipe sewa (harian/bulanan/tahunan) di level kos. Setiap tipe sewa dapat diaktifkan atau dinonaktifkan secara terpisah.
  • Admin memberikan atau mencabut label "Plus" pada kos melalui toggle.
  • Admin mengelola informasi kontak pemilik kos (nama, nomor WhatsApp, nomor telepon).
  • Admin mengaktifkan atau menonaktifkan listing kos.
Manajemen Master Fasilitas
  • Admin dapat menambah item fasilitas baru dengan menentukan nama dan kelompoknya (fasilitas kamar, fasilitas bersama, atau fasilitas sekitar).
  • Admin dapat mengedit nama atau kelompok item fasilitas yang sudah ada.
  • Admin dapat menghapus item fasilitas. Jika item fasilitas dihapus, relasi ke kos yang mencentang fasilitas tersebut ikut terhapus.
Manajemen Ulasan
  • Admin dapat melihat daftar seluruh ulasan yang masuk beserta informasi kos yang diulas, nama reviewer, rating, dan tanggal ulasan.
  • Admin dapat menghapus ulasan dari dashboard.
Manajemen User
  • Admin dapat melihat daftar akun admin yang terdaftar dan akun guest yang telah terdaftar.
  • Admin dapat menambah, mengedit, atau menonaktifkan akun admin lain.
  • Admin dapat melihat dan menonaktifkan akun guest.
Pengaturan Platform
  • Admin dapat mengubah nama platform dan logo melalui halaman pengaturan.
Laporan / Statistik
  • Admin dapat melihat statistik platform: jumlah kos aktif, jumlah kos per tipe, jumlah kos berlabel "Plus", dan jumlah ulasan.

Guest / Penyewa

Autentikasi Guest
  • Guest dapat mendaftar akun baru (register) menggunakan email dan password.
  • Guest dapat login menggunakan email/password atau akun Google (OAuth).
  • Akses browsing, pencarian, dan melihat detail listing tetap tersedia tanpa login.
Landing Page
  • Menampilkan hero section dengan headline, deskripsi singkat platform, dan search bar utama.
  • Menampilkan daftar kos unggulan atau terbaru sebagai pratinjau listing yang tersedia.
  • Menampilkan kategori pencarian cepat berdasarkan tipe sewa (harian, bulanan, tahunan) atau tipe kos (putra/putri/campur).
  • Menampilkan keunggulan platform: listing terkurasi, kos bermitra resmi, dan informasi lengkap.
  • Menyediakan tautan ke halaman listing lengkap dan halaman tentang platform.
Pencarian & Filter Kos
  • Guest dapat mencari kos dengan filter: tipe sewa, rentang harga, lokasi/kecamatan (dropdown), dan tipe kos.
  • Hasil pencarian menampilkan: foto utama kos, nama kos, label "Plus" (jika ada), lokasi, tipe kos, dan rating rata-rata.
  • Guest dapat browsing seluruh listing tanpa perlu login.
Halaman Detail Kos
  • Menampilkan galeri foto kos.
  • Menampilkan nama kos dan label "Plus" (jika berlaku) di samping nama.
  • Menampilkan harga per tipe sewa yang aktif (harian/bulanan/tahunan).
  • Menampilkan informasi umum kos sebagai atribut tersendiri (seperti AC, WiFi, kamar mandi dalam). Atribut yang ditampilkan ditentukan saat development mengacu pada referensi visual sewakost.com.
  • Menampilkan fasilitas dalam tiga kelompok: fasilitas kamar, fasilitas bersama, dan fasilitas sekitar.
  • Menampilkan lokasi kos: nama kecamatan, alamat lengkap, dan embed Google Maps.
  • Menampilkan peraturan kos.
  • Menampilkan kontak pemilik kos: nama, nomor WhatsApp (tombol langsung), dan nomor telepon.
  • Menampilkan ulasan dan rating dari penyewa sebelumnya.
  • Menampilkan rekomendasi kos lain di bagian bawah halaman.
Ulasan & Rating
  • Guest wajib login untuk dapat memberikan ulasan.
  • Ulasan memuat: rating bintang (1–5), komentar teks, dan foto (opsional, maksimal 3 foto dengan ukuran maksimal 2 MB per foto).
  • Guest tidak dapat mengedit atau menghapus ulasan setelah disubmit.
  • Rating kos dihitung sebagai rata-rata dari seluruh ulasan yang masuk untuk kos tersebut.
8

Kebutuhan Non-Fungsional

Keamanan

Autentikasi admin dibangun manual menggunakan Auth::attempt(), Hash::make(), middleware auth, dan session Laravel — tanpa package scaffolding eksternal. Autentikasi guest menggunakan Laravel Socialite untuk login Google. Seluruh form dilindungi CSRF token.

Performa

Lazy loading untuk gambar pada halaman listing. Eager loading Eloquent untuk menghindari N+1 query.

Usability

Tampilan halaman publik mengacu pada referensi visual sewakost.com — bersih, informatif, dan fokus pada konten listing. Dashboard admin menggunakan Flowbite dengan layout sidebar yang konsisten.

Responsivitas

Mendukung desktop dan mobile menggunakan Tailwind CSS.

Maintainability

Struktur kode mengikuti pola Controller → Service → Repository dengan tanggung jawab yang terpisah jelas.

9

Arsitektur dan Implementasi

01

Controller: menerima request HTTP dari Inertia, memanggil Service, mengembalikan Inertia page.

02

Service: menjalankan logika bisnis (filter pencarian, manajemen fasilitas, manajemen user), lalu memanggil Repository.

03

Repository: menangani seluruh query Eloquent — tanpa logika bisnis.

04

React Components: mengonsumsi props dari Inertia. State lokal dikelola dengan useState/useReducer.

05

Komponen UI: dibagi dua — visual utama dibuat custom dengan Tailwind; komponen utilitas interaktif menggunakan shadcn/ui.

06

Laravel Storage: untuk menyimpan foto kos, logo platform, dan foto ulasan.

07

Laravel Socialite: untuk autentikasi Google OAuth khusus guest.

08

Database: skema dirancang di MySQL Workbench (database-first), lalu disinkronkan ke Laravel.
